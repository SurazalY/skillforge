## 1. 增量边界

本矩阵记录超出 pico 的 SkillForge v1 能力。目标不是全量复制 pp-Echo 或 GenericAgent，而是实现三方融合 v1 已确认的控制面：

- pico-size local coding agent runtime。
- pp-style safety/control/evidence/log/audit boundary。
- GenericAgent-style verified skill evolution。
