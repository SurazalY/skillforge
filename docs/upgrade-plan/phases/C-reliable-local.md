# C 阶段：可靠本地运行

阶段执行状态：未启动。启动批准：无。主控：待用户指定。前置：B 已由用户明确关闭。

## 用户得到什么

在 pico 式终端中观察长命令、追加要求、暂停/取消、查看差异与时间线；重启后能知道哪些记录可复用、哪些进程或动作需要协调。前台退出不承诺任务继续。

## 阅读与范围

读[增订](../01-addendum.md)、[开发指南](../02-development-guide.md)、[主控规则](../04-controller-rules.md)、B 报告。原方案定向读 04—05、10—12、09 的验证新鲜度部分。对外服务/Web/SSE 条款按增订延后。

C 扩展 B 的同一数据库与工件合同，不重建调用账本，不并列维护新旧可写状态。不开发 Skill 提炼或多 Agent 调度；运行抽象只做实际本地路径，不做远程 worker 或自动容器平台。
