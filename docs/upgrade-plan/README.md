## 怎样使用

1. 用户与任务分发 Agent 决定是否启动某个阶段。
2. 用户复制对应阶段文件末尾的主控 Prompt，投放到另一套 harness，并使本包与仓库可读。仅生成或读取 Prompt 不等于启动阶段。
3. 阶段主控读取文档、维护该阶段任务表，将代码研究、实现、测试及审查派给子 Agent。
4. 阶段主控完成报告，用户将报告转交任务分发 Agent。阶段主控不能自行宣布阶段关闭或启动下一阶段。
5. 用户明确决定后，任务分发 Agent 更新总进度和报告链接；阶段关闭后提醒用户建立 Git 检查点。
