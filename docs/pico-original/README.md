# Pico Original Documentation

This directory contains the Pico original documentation materials used as the interview-style baseline for SkillForge Pico Fusion.

Notes:

- The original PDF is intentionally not included in this repository sync.
- Markdown/OCR source files are included for review and citation.
- API-key-shaped strings from the original Pico text were redacted as `<redacted>`.
- The `pico-reference/distilled/` files are chapter summaries and navigation aids; use the Markdown source as the primary readable text when exact wording matters.
