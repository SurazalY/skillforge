# Pico Original and SkillForge Fusion Docs

This directory is a mixed documentation area. It contains both Pico original
reference material and actively maintained SkillForge Fusion revision material.
Do not treat the whole directory as archived or deprecated just because the
directory name contains `pico-original`.

## Current Fusion revision entries

These files and folders are current SkillForge Fusion documentation surfaces:

- `SkillForge_Fusion_文档改写计划.md`: writing plan and source mapping for the Fusion rewrite.
- `SkillForge_Fusion_增订说明.md`: main Fusion addendum covering rename, runtime, workflow, evidence, skills, demos, and verification.
- `Workflow_Evidence_Skills_面试问答.md`: interview-style Q&A for workflow, evidence, audit, and verified skills.
- `skillforge-fusion-revisions/`: maintained chapter-level Fusion revisions and additions.
- `skillforge-fusion-revisions/generated-diagrams/`: generated architecture diagrams and prompts for Fusion explanations.

When updating the current architecture narrative, interview explanation, Fusion
addendum, or diagram prompts, start from these entries.

## Pico reference entries

These files and folders are source/reference material:

- `pico-reference/source/`: Markdown/OCR source used for review and citation.
- `pico-reference/distilled/`: chapter summaries, navigation aids, and reuse notes.
- `2-pico_perfect.md`: original Pico-facing material and learning notes.

Use these entries to compare against the original Pico design, recover wording,
trace source facts, or extract expression style. They are not the primary entry
for current SkillForge Fusion implementation usage.

## Notes

- The original PDF is intentionally not included in this repository sync.
- Markdown/OCR source files are included for review and citation.
- API-key-shaped strings from the original Pico text were redacted as `<redacted>`.
- The `pico-reference/distilled/` files are chapter summaries and navigation aids; use the Markdown source as the primary readable text when exact wording matters.
