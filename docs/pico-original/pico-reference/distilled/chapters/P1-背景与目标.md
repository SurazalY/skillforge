## 2. 核心内容摘要
* **编写 Code Agent 的核心价值**：
  在真实的工程落地中，模型外围的配套系统（工具调用、上下文管理、记忆功能等）对最终任务的完成率发挥着不亚于模型本身的作用。Pico 通过构建一个受控的轻量级 Coding Harness，展示如何将模型的潜力发挥到更大。
* **概念边界辨析（基于 Markdown 的信息）**：
  * **大语言模型 (LLM)**：最基础、预测下一个词的生成模型（文中类比为“普通厨师”）。
  * **推理模型 (Reasoning Model)**：优化过、会在生成答案时投入更多推理时间算力 (Test-time compute) 做中间步骤推理与验证的 LLM（类比为“大厨”）。
  * **智能体 (Agent)**：包含了“模型 + 工具 + 记忆 + 环境反馈”的循环控制系统。
  * **Agent Harness (智能体运行框架)**：负责管理上下文、工具调用、提示词、状态和控制流的软件脚手架（类比为“后厨的调度系统”）。
  * **Coding Harness (编程运行框架)**：专门针对软件工程定制的特化版 Agent Harness，管理代码上下文、开发工具、代码执行和迭代反馈（如 Codex, Claude Code）。
